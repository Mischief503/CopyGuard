# Phase 49 — Dashboard Command Center

CopyGuard v4.26.0 redesigns the Dashboard into the production command center.

The home screen now prioritizes:
- system operating mode, automation state, integrity, and observation status;
- source-verified realized Shadow P&L;
- open Shadow exposure and unrealized marked P&L;
- verified outcome count and win rate;
- chronological drawdown and recent performance direction;
- strongest verified wallet contributors;
- active risk/system attention;
- live trade activity;
- Shadow qualification pipeline;
- AI provider readiness, assistant state, Phase 29 learning linkage, and Phase 47 logic-audit status;
- core service health, wallet trust distribution, and automation controls.

Accounting semantics remain strict. Verified realized performance comes only from fully closed, source-verified Shadow outcomes. Open Shadow marks are shown separately and never presented as realized profit.

The dashboard consumes the existing read-only Portfolio Assistant and Logic Audit IPC contracts. It does not create new trading authority or change execution logic.
