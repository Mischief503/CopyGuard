# Phase 35 — Natural-Language Command Router

CopyGuard v4.12.0 upgrades the governed assistant from broad system awareness to deterministic intent routing.

The router recognizes system status, wallet inspection/comparison, token research, risk explanation, Shadow ranking, discovery review, Early Bird review, closed-loop learning review, transaction tracing, Padre preparation, configuration changes, and live-trade requests.

Each intent has an explicit permission and evidence-source contract. The router selects the smallest relevant subset of Phase 34 evidence before the AI provider receives context. Live execution and configuration mutation remain blocked from chat. Padre requests are preparation-only and cannot final-confirm an order.

Every routed request is audited with intent, permission, confidence, evidence sources, entities, and allow/block state.
