# Phase 40 — Shadow / Ghost Coach

CopyGuard v4.17.0 adds a read-only Shadow/Ghost Coach over the verified simulation and qualification system.

The coach explains open Shadow lots, partial realizations, fully closed verified outcomes, current performance, recent-vs-prior trends, deterministic qualification progress, each passed/failed threshold, and the exact next requirement for a wallet.

Only fully closed, source-verified outcomes count toward qualification. Open positions and partial exits remain context and never inflate the completed-trade sample. The coach can rank Shadow wallets by deterministic qualification progress, verified sample size and performance, but the ranking cannot promote a wallet or enable Trusted execution.

Qualification, requalification, Trusted activation, risk hard blocks, and live execution remain governed by their existing deterministic engines.
